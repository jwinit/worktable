# Lingua 日课 · 语言学习工作台

版本：**0.4.0**
形态：响应式静态 Web 应用 / PWA

结合艾宾浩斯间隔复习与费曼输出练习的个人语言学习工作台。默认示例内容为英语词汇，支持切换目标语言、手动建立词库、复习、测验和 Anki 兼容导出。

## 功能

- 首页升级为半年双语冲刺计划，起点为 2026-11-19。英语初始 B1、日语初始五十音入门均为用户自报水平。
- 目标为 IELTS Academic 7.5、JLPT N1 与自然交流。课程中的自编练习成绩不换算考试分数，也不表示目标已达成。
- 每日晨课英语 50 分钟、日语 30 分钟，晚测各 20 分钟。实际时长单独填写，日语超过 50 分钟会提示。
- 支持按日期与六个阶段查看课程、起点诊断、逐题答案与解读、晚测阅读和听力集中评分。
- 错题、到期知识点、最近答案与补充课程记录用于调整后续练习。证据不足时继续使用当前训练阶段。
- 支持实际完成登记、连续打卡、备注、按周分语言统计、答案历史和学习备份导入导出。
- 原词库、文件导入、听说读写材料练习与自动出题入口保留在 `workbench.html`。
- 内置课程为自编基础与阶段示例，结合导入材料练习使用。学习数据保存在浏览器，设备之间通过导出和恢复备份转移。

## 回归检查

```text
node checks.cjs
node sprint-checks.cjs
```

检查覆盖导入解析、语言迁移、英语与日语出题、时间预算、课程日历、真实答题统计、错题间隔、历史记录保护、进阶条件与备份校验。

- 导入资料成功后自动生成题组，在“快速测验”或“材料测验”入口开始答题。
- 已有文章可按原文生成填空选择、填词和听写题，词书可生成释义选择或拼写题，每组最多 10 题。
- 每题保存材料出处与参考答案，提交后显示核对结果。成绩与错题按语言保存，支持单独重做错题。
- 出题采用原文抽取与词书字段组合，适合检查原文记忆和词汇掌握。听写忽略空格、标点与大小写，选择题和填词按参考答案核对。
- 材料需包含至少一个长度为 6–350 字符的句子；短材料会生成较少题目。听写需要浏览器可用的对应语言语音。

- 听力练习支持按材料朗读、调节语速、听写和原文核对。
- 口语练习支持麦克风录音、回放、下载及复述提纲。
- 阅读练习支持主旨与证据笔记、选中原文词汇加入词库。
- 写作练习支持独立草稿、参考理解、自评和费曼查漏。
- 四项练习分别记录完成日期与间隔复习时间。口语和写作采用自评。
- 语言切换同时切换词库、材料、练习和统计。英语、日语提供入门示例，其他语言可导入资料。
- 旧版无语言标记的词库迁移至英语，旧数据存储键仍保留作为备份。
- 批量文件导入支持预览、格式校验和去重。词书支持 CSV / TSV / TXT / JSON，材料支持 TXT / Markdown / SRT / JSON，支持一次选择多个文件。
- 词书表头可用中文、英文或日语。无表头时使用 Tab 分隔的六列。材料 JSON 使用 `[{"title":"标题","text":"正文","reference":"参考理解"}]`。
- 每个文件最多 2 MB，使用 UTF-8。PDF、Word、扫描件需先转换成文本。录音需要 HTTPS 或 localhost 及麦克风权限，下载后可保留录音。

- 今日学习计划：新词、到期复习和快速测验
- 艾宾浩斯复习间隔：1、2、4、7、15、30 天；答错后重新从短间隔开始
- 费曼复述：用自己的话解释词义、补充例句
- 个人词库：单词、读音/音标、释义、例句、用法和标签；支持批量录入
- Anki 导出：制表符分隔的 UTF-8 文本，字段为 Word、Pronunciation、Meaning、Example、Usage、Tags
- 桌面和手机布局，并提供 PWA 安装入口和离线页面缓存
- 词库、进度和提醒设置保存在当前浏览器的本地存储中

## 本地预览

从项目根目录用任一静态 HTTP 服务器将 `dist/` 作为站点根目录。例如：

```powershell
cd dist
python -m http.server 4173
```

然后打开 `http://localhost:4173`。服务工作线程、PWA 安装与浏览器通知需要 HTTP(S) 来源。

## 导入到 Anki

在词库页选择“导出到 Anki”，下载 `lingua-anki-vocabulary.txt`。在 Anki 中导入该文本，分隔符选择 Tab，并将六列映射到对应笔记字段；如果笔记类型还没有这些字段，可先创建或调整笔记类型。

## 提醒说明

提醒使用浏览器通知权限和页面内定时检查；需要在设置中开启通知并保持工作台打开。词库数据仅保存在当前浏览器设备，不会自动跨设备同步。
